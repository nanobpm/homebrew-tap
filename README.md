# nanobpm Homebrew tap

```sh
brew install nanobpm/tap/nano-coder
```

Upgrade with `brew upgrade nano-coder`, or `/update` inside nano-coder.

`Formula/nano-coder.rb` is generated and pushed by the
[nano-coder release workflow](https://github.com/nanobpm/nano-coder/blob/main/.github/workflows/release.yml)
on each release. Don't edit it by hand.
